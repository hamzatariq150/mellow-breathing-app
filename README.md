# 🌬️ Mellow: The Tactile Breathing Pacer

**A sensory anchor and 2-minute mental reset for developers and remote workers.**

Mellow is a zero-friction, single-purpose web app that guides users through a 4-4-4 box breathing exercise. Instead of flat minimalism or overstimulating nature sounds, Mellow uses **Neumorphism (Soft UI)** to create a tactile, physical feeling on a digital screen—acting as a visual fidget toy to ground the nervous system.

## 🎯 The Problem
Developers and remote workers context-switch constantly. When we need a quick mental reset before writing our next Git commit, existing meditation apps are too heavy—they require logins, long time commitments, and visual clutter. Furthermore, standard minimalist UIs lack the sensory feedback needed to truly ground an anxious or overstimulated mind.

## 💡 The Solution
Mellow is a "pre-commit ritual" tool. It sits quietly on a second monitor. You hit spacebar, watch the soft-UI orb breathe, and reset. The deeply shadowed, "pressable" UI provides sensory feedback that helps ground users without requiring audio or complex navigation.

## ✨ Features
- **Visual Box Breathing:** A central orb smoothly expands (Inhale), holds, and contracts (Exhale) over a 12-second cycle.
- **True Neumorphic Design:** Beautifully crafted Soft UI with tactile, "pressable" buttons and inset displays.
- **Zero Friction:** No logins, no backend, no setup. Just open and breathe.
- **Sensory Anchor:** Designed specifically to provide visual and tactile grounding for neurodivergent focus or high-stress moments.

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6)
- **Design:** Custom Neumorphism (Soft UI) CSS architecture
- **Hosting:** GitHub Pages (Static)
