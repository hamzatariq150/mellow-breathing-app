\# Project Scope: Mellow



\## In Scope (v1.0)

\- A single-page web application focused on one core feature: guided box breathing.

\- Neumorphism (Soft UI) design system for a calming, tactile user experience.

\- Visual breathing pacer (expanding/contracting circle).

\- Start/Stop controls with tactile "pressed" UI states.

\- Text prompts guiding the user through Inhale, Hold, and Exhale cycles.



\## Out of Scope

\- User authentication or accounts.

\- Backend database or persistent storage.

\- Multiple breathing techniques (e.g., 4-7-8 method).

\- Audio integration (keeping it purely visual to maintain focus and reduce scope).
